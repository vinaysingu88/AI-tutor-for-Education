  1. Install TypeScript: npm install -g typescript

  3. Compile: tsc --watch
  4. Open: attendance-dashboard.html
  5. Refresh browser to see changes

================================================================================
CUSTOMIZATION
================================================================================

Change Student Data:
  Edit js/attendance-dashboard.js, initializeData() method

Change Colors:
  Edit css/style.css, update CSS variables:
  --color-forest: #27ac1f (green)
  --color-bunker: #0f1f1a (dark text)

Connect to API:
  Replace initializeData() with async fetch call

Change Statistics:
  Edit renderProgressBars() method

Add New Filters:
  Add to filters array in renderFilters() method
